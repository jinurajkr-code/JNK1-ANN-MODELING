# JNK1 ANN Modeling

[![Python](https://img.shields.io/badge/Python-3.9++-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Artificial Neural Network (ANN) regression modeling for predicting JNK1 protein activity (pIC50 values) using molecular descriptors.

## Authors
- **KR JINURAJ**
- **V.N. BALAJI**

## Description
Neural network models to predict JNK1 protein activity using molecular descriptors.

## Installation
```
pip install -r requirements.txt
```

## Usage
```
python JNK1-ANN-MODELING.py
```

## Output Files
- JNK1-ANN-MODELING-RESULTS.csv - Performance summary
- JNK1-ANN-MODEL.pkl - Trained model
- JNK1-ANN-SCALER.pkl - Feature scaler
- Plot PNG files
